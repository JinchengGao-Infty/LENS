# Data

The synthetic data are generated by the code (`experiments/dgps.py`, and
DIAMOND's own generator for F1--F10 in the main comparison). The three public
data sets are not redistributed:

| Data set | How to get it | File expected here |
|---|---|---|
| freMTPL2 claim frequency | Downloaded automatically from OpenML (data ID 41214) by `sklearn.datasets.fetch_openml` | none |
| Default of credit card clients | UCI Machine Learning Repository, dataset 350 (DOI 10.24432/C55S3H), or its Kaggle copy | `UCI_Credit_Card.csv` or `default of credit card clients.xls` |
| HELOC | FICO Explainable Machine Learning Challenge (registration required) | `heloc_dataset_v1.csv` |

Preprocessing is in `experiments/real_data_loader.py` (credit) and
`lens/experiments/fremtpl2_poisson_allpair.py` (freMTPL2).
